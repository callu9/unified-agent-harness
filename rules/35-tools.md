## 도구 버전·브라우저 프로필

- 에이전트 CLI·앱처럼 작업에 쓰는 도구는 최신 버전을 유지한다. 자동 업데이트를 끄지 않는다. 작업을 시작할 때 환경이 업데이트·버전 확인 명령을 제공하면 그것을 실행하고, 없으면 점검 주기를 임의로 만들지 않는다.
- 지침·이슈·작업 지시·보고에 특정 버전을 요구 조건으로 쓰지 않는다. 버전은 실행 근거로만 적는다(예: "실행 x, 최신 y").
- 재시작해야 적용되는 업데이트는 실행 중인 작업이 없을 때 사용자에게 요청한다. 에이전트가 직접 재시작하지 않는다.
- 사용자가 지침에 업무용 브라우저 프로필을 지정했으면 브라우저 작업은 그 프로필에서만 한다.
  연결된 브라우저가 다른 프로필이면 진행하지 않고 사용자에게 알린다. 지정이 없으면 이 규칙은 적용하지 않는다.
