# 학습 계획 설계하기

1. 현재 수준, 목표 과제, 학습 가능 시간을 파악한다. 목표 실력을 실제로 수행할 수 있는 과제로 표현한다.
2. 목표에 직접 필요한 약점을 우선한다. 약점 연습, 배운 내용을 자료 없이 떠올리는 복습, 간격을 둔 재연습, 작은 실습 과제를 가용 시간 안에 배치한다.
3. 기간별로 무엇을 연습하고 어떤 결과를 확인할지 제시한다. 점검 과제에서 막히면 다음 연습을 그 약점에 맞춰 조정한다.

예시 요청 · SQL 기초는 알아. 주 4시간씩 4주 안에 업무 지표를 직접 조회할 수 있게 계획을 짜줘.
