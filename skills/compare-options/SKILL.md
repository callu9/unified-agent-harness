# 선택지 비교하기

1. 필수 제약과 선호를 구분한다. 사용자의 우선순위를 그대로 쓰고, 필수 조건을 충족하지 못하는 후보는 어떤 조건을 충족하지 못했는지 표시한다.
2. 선택지에 같은 기준을 적용한다. 결정에 영향을 주는 비용, 위험, 다른 선택을 포기하는 비용, 장기 영향만 남긴다. 수치에는 근거와 불확실성을 표시한다.
3. 비교 결과와 추천 이유를 제시한다. 알려지지 않은 비용이나 바뀔 수 있는 제약이 추천을 뒤집는다면 전환 조건을 적는다.

예시 요청 · 이 기능을 직접 만들지 외부 서비스를 쓸지 비교해줘. 출시 속도와 1년 유지비가 중요해.
