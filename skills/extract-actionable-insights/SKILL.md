# 자료에서 실행할 내용 추출하기

1. 자료와 사용자가 내리려는 결정을 확인한다. 관련 있는 주장, 근거, 숨은 전제, 결론을 바꿀 수 있는 반대 근거를 골라낸다.
2. 자료가 직접 뒷받침하는 내용과 해석을 구분한다. 핵심 근거마다 페이지, 절, 문단, 발언자나 타임스탬프 등 실제로 확인 가능한 위치를 붙인다.
3. 중요한 발견을 적용할 행동이나 확인할 질문으로 연결한다. 자료가 충돌하거나 근거가 부족한 부분은 무엇을 더 확인해야 하는지 적는다.

예시 요청 · 인터뷰 녹취에서 다음 제품 개선에 반영할 내용과 근거가 되는 발언 위치를 뽑아줘.
