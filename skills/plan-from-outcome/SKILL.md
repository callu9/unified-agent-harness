# 완료 조건에서 역산하기

1. 마감과 함께 누가 무엇을 확인하면 완료인지 정한다. 현재 상태와 목표의 차이를 확인한다.
2. 완료에 바로 필요한 상태에서 출발해 선행 작업과 의존성을 거꾸로 찾는다. 일정이 주어졌다면 병목과 여유가 필요한 곳을 짚는다.
3. 실행 순서로 이정표를 보여주고 각 단계의 선행 조건과 완료 확인 방법을 적는다. 바로 시작할 수 있는 첫 작업을 제시한다.

현재 자원이나 기한으로 일정이 성립하지 않으면 부족한 조건과 가능한 범위 조정을 밝힌다.

예시 요청 · 6주 뒤에 베타를 공개하려고 해. 공개 조건부터 역산해서 주별 계획을 짜줘.
