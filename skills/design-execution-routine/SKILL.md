# 반복 실행 방식 설계하기

1. 목표와 현재 실행을 방해하는 지점을 확인한다. 반복할 최소 행동, 시작 신호, 실행할 시점을 정한다.
2. 실행 여부를 바로 확인할 지표와 목표에 가까워지는지 확인할 지표를 정한다. 점검 주기와 점검 결과에 따라 무엇을 바꿀지도 적는다.
3. 루틴을 놓쳤을 때 다시 시작할 다음 시점과 최소 행동을 제시한다. 지금 바로 실행할 첫 회차가 무엇인지 밝힌다.

예시 요청 · 매주 고객 인터뷰 두 건을 꾸준히 하도록 일정과 점검 방식을 설계해줘.
